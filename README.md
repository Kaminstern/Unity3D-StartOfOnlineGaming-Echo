### 5.1.2节传输层P135中，“由于IP协议最大的数据长度是65515字节，TCP...”

> 应该说的是IP头部有一个16位总长度字段，最大表示 `2^16 - 1 = 65535` 字节。这个 65535 是 **IP 总长度**， 即
>
> ```
> IP 总长度 = IP 头部 + IP 载荷
> ```
>
> IP 头部最小 20 字节，所以
>
> ```
> IP 载荷最大 = 65535 - 20 = 65515 字节
> ```
>
> 所以 65515 是 IP 载荷的最大值，不是“IP 协议最大数据长度”。

> TCP 头部最小 20 字节。TCP 报文段作为 IP 的载荷，所以：
>
> ```
> IP 载荷 = TCP 头部 + TCP 数据（用户数据）
> ```
>
> 因此
>
> ```
> TCP 用户数据最大 = IP 载荷最大 - TCP 头部
>                = 65515 - 20
>                = 65495 字节
> ```
>
> 不是 65515。

### 5.3.6节LingerState，P143中，“第二个参数是LingerState.LingerTime，指定超时时间。如果...”

> 当LingerState.LingerTime设置为0时，应该是立即**立即丢弃**发送缓冲区里的数据，并发送 RST 强制关闭连接。
> 大于0时，最多等 `seconds` 秒，把剩余数据发完并正常四次挥手；超时还没发完就丢弃，强制关闭。
> 当LingerState.Enabled设置为false时，默认行为，`Close()` 立即返回，后台继续尝试发送剩余数据（正常 TCP 关闭流程）。
