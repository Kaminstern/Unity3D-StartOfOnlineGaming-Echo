5.1.2节传输层P135中，“由于IP协议最大的数据长度是65515字节，TCP...”

> 应该说的是IP头部有一个16位总长度字段，最大表示 `2^16 - 1 = 65535` 字节。这个 65535 是 **IP 总长度**， 即
>
> ```
> IP 总长度 = IP 头部 + IP 载荷
> ```
>
> IP 头部最小 20 字节，所以
>
> ```
> IP 载荷最大 = 65535 - 20 = 65515 字节
> ```
>
> 所以 65515 是 IP 载荷的最大值，不是“IP 协议最大数据长度”。

> TCP 头部最小 20 字节。TCP 报文段作为 IP 的载荷，所以：
>
> ```
> IP 载荷 = TCP 头部 + TCP 数据（用户数据）
> ```
> 因此
>
> ```
> TCP 用户数据最大 = IP 载荷最大 - TCP 头部
>                = 65515 - 20
>                = 65495 字节
> ```
> 不是 65515。
